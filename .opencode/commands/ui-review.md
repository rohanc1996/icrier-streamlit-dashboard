Review the UI/UX of **$ARGUMENTS** (default: the page currently being worked on).

1. Read the view module, the shared helpers it uses (`components/ui.py`,
   `components/charts.py`, `core/themes.py`), and one sibling page for
   consistency.
2. Run the dashboard if needed, or use the screenshot I provide. Do not guess
   what the page looks like.
3. List the **three highest-impact** problems, each with the specific element
   and why it hurts the user. Separate layout, hierarchy, chart legibility,
   interaction and accessibility issues.
4. Propose the smallest fix for each. Ask before a redesign.
5. Implement only what I approve. Keep scoring and data logic untouched, and do
   not add dependencies.

Finish with what a reviewer should look at, and ask for a screenshot of the
result if the change is visual.
